
# User Guide

## Running the Application

### Step 1
Open the TREE-ENUMERATION project in GitHub Codespaces.

### Step 2
Open the terminal.

### Step 3
Install the required libraries:

pip install -r requirements.txt

### Step 4
Run the Streamlit application:

streamlit run app.py

### Step 5
Open the application using the forwarded port provided by GitHub Codespaces.

## Uploading Images

1. Open the application.
2. Select the forest image upload option.
3. Upload a supported image.
4. Start the tree detection process.
5. View the detected trees and enumeration results.

## Outputs

The application can provide:

- Tree detection visualization
- Estimated tree count
- Tree distribution maps
- Data analysis
- Downloadable reports
