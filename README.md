# TREE-ENUMERATION

## About the Project

Tree Enumeration is an AI-powered application developed to make tree monitoring easier and more efficient. It uses drone and satellite images to identify, count, and classify trees automatically.

The application helps analyze forest density, understand tree distribution, and estimate future tree populations using historical data and machine learning. It aims to reduce manual effort and provide useful insights for forest monitoring and environmental conservation.

##  Features

- **Tree Detection:** Detects individual trees from drone and satellite images.
- **Tree Counting:** Automatically counts the detected trees.
- **Tree Classification:** Groups trees based on their size.
- **Forest Density Analysis:** Provides insights into tree distribution and forest coverage.
- **Visual Results:** Displays detection results and analysis through interactive visualizations.
- **Future Prediction:** Estimates future tree population using historical data.

##  How It Works

1. Upload a drone or satellite image.
2. The system processes the image using computer vision techniques.
3. AI models identify and detect individual trees.
4. Detected trees are counted and classified based on size.
5. Forest density and distribution are analyzed.
6. Results are displayed through visualizations and reports.

##  Getting Started

**Clone the repository:**

```bash

```

**Move into the project folder:**

```bash
cd Tree-Enumeration
```

**Install the required libraries:**


**Run the application:**

```bash
streamlit run app.py
```
